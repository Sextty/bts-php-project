# Archives Mermaid - ne pas utiliser dans le rapport

Les dix fichiers `.mmd` de ce sous-dossier sont des copies historiques creees avant les phases finales du projet. Ils contiennent des informations devenues fausses ou incompletes (Laravel 11, MySQL 8, trois portails seulement, colonnes et statuts inventes, anciennes routes et ancien nom de canal Reverb).

Ils sont conserves uniquement pour l'historique et sont classes **DUPLICATE / OUTDATED** dans `docs/report/BTS_DIAGRAM_AUDIT.md`.

Les sources actives et validees se trouvent directement dans `diagramme/`, et leurs images correspondantes dans `diagramme/img/`.
